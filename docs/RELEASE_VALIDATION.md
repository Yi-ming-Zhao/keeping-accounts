## 体积与运行

- 正式 ARM64 APK：24,242,379 字节（约 24.24 MB，低于 40 MB 目标）。
- 清除模拟器测试数据后的应用冷启动：697 ms（`am start -S -W`）。
- 启动后等待 30 秒采样：青账进程 CPU 显示 0%。该结果不能代替 vivo 实机耗电评估。
- 源码和 APK 在冻结时扫描实际使用的测试密钥，不得包含密钥、签名私钥或本地配置。

APK 和源码压缩包的最终 SHA-256、原生库列表、测试 XML 摘要见 Release 附件 `verification.json` 与 `SHA256SUMS`。开发过程日志不公开。

## 仍未验证

vivo X100 Pro 的后台限制、真实微信/支付宝/京东/拼多多等应用当前版本页面、无障碍混淆节点、受保护页面的厂商差异，以及长时间耗电。样本应用触发系统服务，不等于这些第三方应用的真实支付路径已经通过验收。

没有为测试自动购买、付款、退款或操作任何第三方支付按钮。
