# 青账 0.2.1

发布日期：2026-10-21。正式版，versionCode 5，Android 11+，ARM64。沿用既有应用签名、包名和数据库结构，从 0.2.0 直接覆盖安装，不要卸载。

## 本版修复

- 通知服务恢复连接、应用新增授权时，补读通知栏里仍存在的通知。
- 支付通知按发送者和消息时间逐条处理，支持消息数量标题、折叠行及同行交易字段。重复推送去重，两笔同额消息分别保留。
- 支持“支付成功，实付款：6.38元，商户：京东”这类同行字段；不会将同一单据中的商品原价 10 元当作实付。
- 修复带搜索框、多个字段合并在一个节点、持续刷新的购物订单页漏采集。
- 设置区分权限已开与服务实际连接，展示最近采集结果，并可复制不含交易正文、金额和密钥的诊断。
- 修正候选版到正式版的版本比较。

## 验证范围

通知和页面样本由独立测试应用提供，经 Android 系统通知监听和无障碍服务处理后，检查本地加密账本。没有直接调用入账函数来代替触发测试，也没有为测试发起付款。

| 检查 | 结果与证据 |
| --- | --- |
| 通知来源、聊天隔离、折叠行、金额冲突、币种及原有金额规则 | 19 项单元检查通过，见 [通知修复记录](NOTIFICATION_FIX_0.2.1_RC2.md) |
| 未打开订单页的通知入账、多消息、同额消息及重复推送 | 签名 rc2 包通过；正式版保持相同处理代码 |
| 重连、新授权补读、原生消息与折叠格式 | 与上述通知路径合计 7 项 Android 检查通过 |
| 订单页搜索框、合并节点、连续刷新、隐私边界及设置诊断 | 见 [页面修复记录](CAPTURE_FIX_0.2.1.md)；正式版保持相同处理代码 |

## 实际使用仍待确认

尚未在 vivo X100 Pro、OriginOS 后台环境或真实微信、京东、拼多多应用中验收。测试覆盖的通知结构不是微信当前版本必然输出的格式。此次发布经使用者明确要求，用于实际使用和问题反馈；不能认定此前那笔京东漏记的唯一原因已查明。

没有可读支付通知，且未采集到可读交易页面时，应用无法得知付款；已消失的通知不能补读。只有金额证据时先记金额，商品与分类保持待补充。没有共同编号的跨应用记录仍可能需要人工核对。不会自动打开、点击或翻动支付应用。

如果付款后漏记，可在“设置 → 采集 → 查看采集状态”查看服务连接和最近处理结果，复制诊断用于反馈。诊断不包含交易正文。
