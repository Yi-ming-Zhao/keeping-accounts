### 安装

下载 `keeping-accounts-0.2.0-arm64.apk`，支持 Android 11+ ARM64。**覆盖安装 0.1.0，无需卸载。** 已验证同签名升级保留账目和设置。模型密钥需要用户自行配置，发布包不含任何密钥。

安装包约 24.24 MB。旧版已存在的金额不会无提示改写；已有证据与账面金额冲突时会标记待核对，可在详情中编辑。
